# NavRouter-CIL 工作匯報（2026-10-08）

## 二、系統怎麼運作

| 步        | 做什麼                                                       | 要存什麼                                     |
| --------- | ------------------------------------------------------------ | -------------------------------------------- |
| 1. 判器官 | 整片所有 patch 的平均向量 → 閉式 ridge 分派器 → 器官         | 一個 513×513 累加矩陣（共用），每任務一欄    |
| 2. 挑證據 | 每個 patch 對該器官兩類文字算相似度當分數，修正頭加一個修正量；分四輪各挑 16 個、避開相似的，共 64 個 → 平均成一個向量 | 每任務兩個文字向量、一個修正頭（1,033 參數） |
| 3. 判亞型 | 證據向量 → 和第 1 步同一種閉式 ridge → 在該器官兩類內取大    | 一個 513×513 累加矩陣（共用），每任務兩欄    |

學新任務：訓練修正頭（4–30 秒）、累加統計量進兩個矩陣、刪切片。四個任務合計 2.16 MB。四個任務學完後的判定與順序無關。

### 修正頭是什麼

每個任務一個、接在凍結特徵上的小模組，給每個 patch 的文字分數加一個修正量。

輸入（每個 patch $i$，514 維）：

$$
u_i=\begin{bmatrix} z_i \\ m_i \\ e_i \end{bmatrix},\qquad
z_i\in\mathbb{R}^{512}\ \text{CONCH patch 特徵},\quad
m_i=\max_{c\in\{1,2\}}\cos(z_i,t_c),\quad
e_i=H\big(\mathrm{softmax}(\cos(z_i,t_1),\cos(z_i,t_2))\big)
$$

兩層：

$$
h_i=\mathrm{GELU}(W_1u_i+b_1),\quad W_1\in\mathbb{R}^{2\times514},\ b_1\in\mathbb{R}^{2};\qquad
g_i=w_2^{\top}h_i+b_2,\quad w_2\in\mathbb{R}^{2},\ b_2\in\mathbb{R}
$$

輸出加到文字分數上：

$$
s_i=s_{0,i}+g_i,\qquad s_{0,i}=\text{z-score}_{\text{切片內}}(m_i)
$$

| 參數  | 形狀    | 個數      |
| ----- | ------- | --------- |
| $W_1$ | 2 × 514 | 1,028     |
| $b_1$ | 2       | 2         |
| $w_2$ | 2       | 2         |
| $b_2$ | 1       | 1         |
| 合計  |         | **1,033** |

$W_1$ 的兩列是特徵空間裡學出來的兩個方向；每個 patch 在這兩個方向上的投影，加上它的文字相似度與 entropy，經 GELU 後由 $w_2$ 合成一個修正量。寬度 2 來自 LoRA 實驗的 rank 2：rank 1 有數值問題，再寬沒有更準。

| 項目                 | 內容                                                         |
| -------------------- | ------------------------------------------------------------ |
| 訓練資料             | 該任務的訓練切片，只用亞型標籤                               |
| 前向                 | 依分數挑 64 個 patch（挑選不傳梯度），依分數做 softmax 加權平均成一個向量，對兩類文字算 cosine 乘 CONCH 的 logit scale 當 logits |
| 損失與設定           | 交叉熵；Adam 5e-4、5 個 epoch；CPU 每任務 4–30 秒；訓練後凍結 |
| 和別人的打分器差在哪 | attention-MIL（ABMIL、CLAM）從零學 patch 的分數，隱藏 128–256、十萬級參數，多半一個模組共用；我們的分數先由文字給定，模組只學修正量，1,033 參數，每任務一個、訓練後凍結、不共享 |
| 效果                 | 拿掉修正頭 0.921，加上 0.925，差 0.4 pp，十折 7 比 3，不顯著。修正量相對文字分數：食道 0.31、腎 0.56、乳房 1.86、肺 1.21，文字分得清的器官修正小 |

**G/C/A/B——A和B我會改成S和R避免和LoRA混淆**：
G、C、A、B 四個都不是「模型參數」，是訓練切片的累加統計量；G、C 用來判器官，A、B 用來判亞型；分類器本身是從它們一次算出來的（閉式解），不用梯度。和 LoRA 的 A、B 同名但完全無關。

**四個矩陣是什麼**

| 符號 | 定義                                 | 形狀      | 累加的是誰                                  | 用來做什麼                                                   |
| ---- | ------------------------------------ | --------- | ------------------------------------------- | ------------------------------------------------------------ |
| $G$  | $\sum_{\text{訓練切片}} x\,x^{\top}$ | 513 × 513 | 整片平均向量 $x$（補一個 1）                | 判器官：所有訓練切片的 $x$ 之間的二階統計量（未中心化的共變異） |
| $C$  | $\sum x\,y^{\top}$                   | 513 × T   | $x$ 與任務 one-hot $y$                      | 判器官：每個任務一欄，等於該任務所有訓練切片 $x$ 的總和      |
| $A$  | $\sum \bar v\,\bar v^{\top}$         | 513 × 513 | 證據向量 $\bar v$（64 張 patch 平均，補 1） | 判亞型：所有任務共用一個                                     |
| $B$  | $\sum \bar v\,y^{\top}$              | 513 × 2T  | $\bar v$ 與類別 one-hot $y$                 | 判亞型：每類一欄，每任務加兩欄                               |

**為什麼要它們**：線性分類器 $W$ 的最小平方解（加 ridge 正則化）只需要這兩種和：

$$
W_{TP}=(G+\gamma I)^{-1}C,\qquad W=(A+\gamma I)^{-1}B,\qquad \gamma=10^{-3}
$$

也就是說，$W$ 不是學出來的，是從 $G,C$（或 $A,B$）直接解出來的。這就是 analytic CL（ACIL、RanPAC、FeCAM 一脈）的做法。

**怎麼做到持續學習**

| 步驟              | 做什麼                                                       |
| ----------------- | ------------------------------------------------------------ |
| 學任務 τ          | 對它的每張訓練切片算 $x$ 和 $\bar v$，把 $x x^{\top}$ 加進 $G$、$\bar v \bar v^{\top}$ 加進 $A$；$C$ 多一欄（任務 τ）、$B$ 多兩欄（它的兩類）；然後刪切片 |
| 推論              | 從當前的 $G,C$ 解出 $W_{TP}$ 判器官；從 $A,B$ 解出 $W$，只看判到器官的兩欄 |
| 為什麼不遺忘      | 舊任務的切片早就累加進去了，矩陣裡的貢獻不會被新任務蓋掉；四個任務學完後 $G,C,A,B$ 和順序無關，所以最後的判定也和順序無關 |
| 為什麼不算 replay | 矩陣是幾千張切片的總和，還原不出任何一張；大小固定 2 × 1 MB，不隨任務數增長 |

**對應到熟悉的 CL 詞彙**

# 無 replay 的 WSI CL:先辨識 Task, 再判Subtype（CIL）

簡報版 2026/09/30

---

## 0. Recap

每張 slide 分兩步判斷:先判斷是哪一種癌症(**Task-ID Prediction, TP**),再在該癌症內判斷亞型(**Within-task Prediction, WP**)。

- TP 用 **closed-form ridge classifier**:只靠可以累加的統計量更新,不需要回頭看舊 slide。
- WP 每個癌症一個 **residual scoring head**(1,033 參數),學完就凍結。

整個系統不保留任何舊 slide。CIL ACC 為 0.9128,高於 QPMIL-VL 的 0.859(reverse)/ 0.890(forward)。

---

## 1. 問題設定

| 項目                   | 內容                                                         |
| ---------------------- | ------------------------------------------------------------ |
| 任務                   | 依序學 4 種癌症(ESCA、RCC、BRCA、LUNG),各 2 個亞型,共 8 類   |
| Class-incremental(CIL) | 測試時不告訴模型這張 slide 屬於哪個癌症                      |
| 限制                   | 舊病人的 slide 必須可以刪除,學新任務時不能再讀舊 slide(no replay) |
| 特徵                   | CONCH 凍結不訓練;每張 slide 切成 N 個 patch(約數千個),每個 patch 是 512 維向量 |

---

## 2. 核心觀察:錯誤主要來自「猜錯癌症」

CIL 的正確率可以近似拆成兩部分(Kim et al., NeurIPS 2022;也就是老師先前的乘法估算):

$$\text{ACC} \approx \text{TP 正確率} \times \text{WP 正確率}$$

| 設定                             | ACC    |
| -------------------------------- | ------ |
| 告訴模型是哪個癌症 TIL (WP only) | 0.9340 |
| Task Unknown CIL(TP + WP,Ours)   | 0.9128 |

WP 已經有 0.93,兩者的差距 2.1 pp 全部來自 TP 猜錯。所以方法的設計目標只有兩個:

1. 讓 TP 猜得準;
2. 讓 WP 的各任務模型互不干擾,學新任務時不會忘掉舊的。

---

## 3. 架構

```
WSI
 └─ CONCH image encoder(凍結)
      └─ patch features Z : N × 512
           │
           ├─【TP】mean pooling → x : 513(L2 正規化後補 1 維 bias)
           │        → ridge weights W = (G + γI)⁻¹C : 513 × t   (t = 已學任務數)
           │        → task scores : t → argmax → 任務 τ̂
           │
           └─【WP】只用任務 τ̂ 的 head
                    → 每個 patch 一個分數 s = s0 + g : N
                    → 挑分數最高的 64 個 patch → 平均 → 512
                    → 與 τ̂ 的 2 個亞型文字向量比 cosine → 亞型
```

從訓練資料學到的只有兩樣:TP 的 W(由統計量 G、C 以閉式解一次算出,不用梯度下降)、每任務一個 residual scoring head(用梯度訓練,學完凍結)。CONCH 的 image encoder 與 text encoder 都不動。

---

## 4. TP:Closed-form Ridge Task Classifier

### 4.1 兩個統計量與權重

每張 slide 先壓成一個向量:

$$x = \big[\ \widehat{\text{mean}(Z)}\ ;\ 1\ \big] \in \mathbb{R}^{513}$$

也就是把 N 個 patch 逐項平均、L2 正規化,再補一個常數 1(bias)。

TP 只保留兩樣東西:

| 名稱               | 定義                                                   | 形狀      | 白話                                                         |
| ------------------ | ------------------------------------------------------ | --------- | ------------------------------------------------------------ |
| **G**(Gram matrix) | $G = \sum_{\text{所有訓練 slide}} x^\top x$            | 513 × 513 | 所有 slide 整體有哪些特徵常一起變強。**所有任務共用一份**,不需要知道任務 |
| **c_τ**(class sum) | $c_\tau = \sum_{\text{任務 } \tau \text{ 的 slide}} x$ | 513       | 任務 τ 的 slide 向量加總;除以 slide 數就是這個癌症的平均樣子。**每任務一份** |
| **C**              | $C = [\,c_1, \dots, c_t\,]$                            | 513 × t   | 把各任務的 c 並排                                            |

權重由這兩者直接算出(ridge 的閉式解,γ = 10⁻³):

$$W = (G + \gamma I)^{-1}\, C$$

判斷:$\hat\tau = \arg\max_\tau\ (x\,W)_\tau$

意思是:C 提供每個癌症的樣子;乘上 $G^{-1}$,會把所有 slide 共有的強勢方向縮小,留下能區分癌症的方向。

### 4.2 Shape 演進

| 步驟                         | Shape     |
| ---------------------------- | --------- |
| patch features Z             | N × 512   |
| 平均、L2 正規化、補 bias → x | 513       |
| G(所有任務共用)              | 513 × 513 |
| C(每任務一欄)                | 513 × t   |
| W = (G + γI)⁻¹ C             | 513 × t   |
| task scores = x W            | t         |
| 輸出                         | 1 個任務  |

### 4.3 為什麼學新任務不用看舊 slide

G 和 C 都是**加總**,可以分段累加:

- 每張訓練 slide:把 $x^\top x$ 加進 G;把 $x$ 加進它所屬任務的 $c_\tau$。
- 一個任務的 slide 都加完之後,這些 slide 就可以刪除。
- 下一個任務來時,繼續往同一個 G 上加,並新增一欄 $c_t$。

最後得到的 G、C,跟把所有 slide 一次拿來算的**完全相同**,所以 W 也完全相同。

**手算例子(示意:每張 slide 簡化成 2 維,不含 bias,γ = 0)**

步驟 1:從 patch 到 x(以任務 1 的兩張 slide 為例)

| slide | patch 向量             | 平均       | 正規化後的 x |
| ----- | ---------------------- | ---------- | ------------ |
| a     | (2, 0)、(1, 0)、(3, 0) | (2, 0)     | (1, 0)       |
| b     | (1.2, 0.9)、(0.4, 0.3) | (0.8, 0.6) | (0.8, 0.6)   |

任務 2 的兩張 slide 同樣處理後,得到 c:(0, 1)、d:(0.6, 0.8)。

步驟 2:任務 1 到來,累加後刪除 slide

| slide  | $x^\top x$                       |
| ------ | -------------------------------- |
| a      | [[1, 0], [0, 0]]                 |
| b      | [[0.64, 0.48], [0.48, 0.36]]     |
| **G**  | [[1.64, 0.48], [0.48, 0.36]]     |
| **c₁** | (1, 0) + (0.8, 0.6) = (1.8, 0.6) |

保留 G 與 c₁,刪除 slide a、b。

步驟 3:任務 2 到來,往同一個 G 上加

|                           | 計算                                            | 結果                         |
| ------------------------- | ----------------------------------------------- | ---------------------------- |
| 任務 2 的 $\sum x^\top x$ | [[0, 0], [0, 1]] + [[0.36, 0.48], [0.48, 0.64]] | [[0.36, 0.48], [0.48, 1.64]] |
| **G**                     | 舊 G + 任務 2 的量                              | [[2.00, 0.96], [0.96, 2.00]] |
| **c₂**                    | (0, 1) + (0.6, 0.8)                             | (0.6, 1.8)                   |
| **C**                     | [c₁ c₂]                                         | [[1.8, 0.6], [0.6, 1.8]]     |

這一步沒有用到 slide a、b。

步驟 4:算 W 並判斷新 slide

|                          | 計算                                 | 結果                               |
| ------------------------ | ------------------------------------ | ---------------------------------- |
| $G^{-1}$                 | 行列式 2.00 × 2.00 − 0.96² = 3.0784  | [[0.650, −0.312], [−0.312, 0.650]] |
| W 的任務 1 欄            | $G^{-1} c_1$                         | (0.982, −0.172)                    |
| W 的任務 2 欄            | $G^{-1} c_2$                         | (−0.172, 0.982)                    |
| 新 slide x = (0.9, 0.44) | 任務 1:0.9 × 0.982 + 0.44 × (−0.172) | **0.81**                           |
|                          | 任務 2:0.9 × (−0.172) + 0.44 × 0.982 | 0.28                               |

判為任務 1。

比較 c₁ 與 W 的任務 1 欄:c₁ = (1.8, 0.6) 對特徵 2 仍給正的權重;乘上 $G^{-1}$ 後變成 (0.982, −0.172),特徵 2 變成負的,代表「特徵 2 越強,越不像任務 1」。這就是判別的效果。

步驟 5:驗證與一次全部訓練相同

把 a、b、c、d 疊成矩陣 X(4 × 2)、one-hot 標籤 Y(4 × 2):$X^\top X$ 就是四張 slide 的 $x^\top x$ 相加,等於 G;$X^\top Y$ 的兩欄就是 a + b 與 c + d,等於 C。所以 W 完全相同。

### 4.4 為什麼比 T-Hard、群中心準

| 做法            | 判斷依據                                                     | 問題                                                         |
| --------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| T-Hard / 群中心 | 新 slide 跟哪個癌症的「平均樣子」最像(相當於只用 C)          | 肺和食道的平均樣子很接近,因為大部分成分(染色、背景)是所有癌症共有的 |
| Ridge           | $W = G^{-1} C$:G 記錄了所有癌症共有的成分,乘上 $G^{-1}$ 把這些方向壓低,專看能區分癌症的方向 | —                                                            |

實測:肺被猜成食道的張數,群中心是 39 張,ridge 是 2 張(十折合計,965 張肺的測試片)。

## 5. WP:Text-guided Evidence Selection + Residual Scoring Head

:::success
這部分的簡單說明：
已經知道是哪種癌症之後,我們要從幾千個 patch 裡,找出跟判斷亞型最有關的區域。

第一步,用 CONCH 直接比對:每個 patch 跟兩個亞型的文字描述有多像,越像的分數越高。這一步不用訓練,就是 zero-shot 分數。

第二步,zero-shot 分數大致對,但會排錯一些 patch。所以每個癌症配一個很小的網路,大約一千個參數,學的是「哪些 patch 被高估、哪些被低估」,給一個加分或扣分。

第三步,把兩個分數加起來,挑最高的 64 個 patch,平均之後,看它比較像哪個亞型的描述,就判那個亞型。

這個小網路一開始輸出 0,所以訓練是從 zero-shot 出發,只學修正的部分。每個癌症的網路學完就凍結,不會被後面的任務改掉。
:::
### 5.1 怎麼算

對任務 τ̂ 的兩個亞型文字向量 $t_1, t_2$(CONCH text encoder 編碼,prompt 與 QPMIL-VL 相同):

1. **Zero-shot 分數**:每個 patch 與兩個亞型文字的最大 cosine,在同一張 slide 內做 z-score,得到 $s^0$。不需要訓練。
2. **Residual scoring head**(每任務一個,1,033 參數):
$$g = w_2^\top\,\text{GELU}(P\,u + b_1) + b_2,\qquad u = [\,z;\ \text{最大 cosine};\ \text{熵}\,] \in \mathbb{R}^{514},\quad P \in \mathbb{R}^{2\times 514}$$
P 是把 514 維壓到 2 維的投影(projection),跟 TP 的 G、C 無關。
3. **最終分數** $s = s^0 + g$。$w_2$ 初始化為 0,所以訓練是從 zero-shot 分數出發,只學「哪裡排錯了」。
4. 依 $s$ 挑 64 個 patch,平均後與 $t_1, t_2$ 比 cosine,較大者即為亞型。

Head 只影響「看哪些 patch」;最後判亞型這一步沒有可學參數。

### 5.2 Shape 演進與實測例子

以 fold 1 的一張 ESCA 測試片為例(共 6,318 個 patch),追蹤其中一個 patch:

| 步驟                                         | Shape | 這個 patch 的實際數值                              |
| -------------------------------------------- | ----- | -------------------------------------------------- |
| patch feature z                              | 512   | —                                                  |
| 與兩個亞型文字的最大 cosine、熵              | 2     | 0.5485、0.6931                                     |
| 輸入 u                                       | 514   | —                                                  |
| zero-shot 分數 s⁰                            | 1     | 2.3883(在 6,318 個 patch 中排第 73 名,擠不進前 64) |
| P u + b₁                                     | 2     | 11.70、11.83                                       |
| GELU                                         | 2     | 11.70、11.83                                       |
| 修正量 g = w₂ · (…) + b₂,w₂ ≈ (0.056, 0.054) | 1     | 1.29                                               |
| 最終分數 s = s⁰ + g                          | 1     | 3.68(升到第 12 名,被選入)                          |

在十折的平均下,有沒有 head,挑出的 64 個 patch 只有約 30 個相同。Head 實際改變了模型看的區域。

### 5.3 為什麼每任務一個獨立的 head

- 學新任務時訓練的是新的 head,舊的 head 完全不動,所以 WP 不會遺忘。
- Head 是 bottleneck 結構(514 → 2 → 1),參數很少。每任務只有幾百張訓練 slide,參數少比較不容易 overfit。
- 它不是 LoRA:LoRA 是在既有權重上加 $BA$;這個 head 沒有修改任何既有權重,是加在 zero-shot 分數上的一個小修正,精神接近 CLIP-Adapter。

## 6. 為什麼不是 replay

**Replay 的定義**:學第 t 個任務時,讀取第 1 到 t−1 個任務的 slide 或 slide 特徵。

| 檢查                                                  | 本方法                                                       |
| ----------------------------------------------------- | ------------------------------------------------------------ |
| 學新任務時,讀取舊 slide 嗎?                           | 不讀。TP 只把新任務的 $\sum x^\top x$ 加到 G 上,並新增一欄 $c_t$;WP 只訓練新任務的 head |
| 有沒有被新任務改動、因此需要舊資料「拉住」的共用參數? | 沒有。舊 head 凍結;TP 的更新是加法,結果與一次看完全部資料相同 |
| 刪掉一位舊病人的 slide,系統受影響嗎?                  | 不受影響                                                     |

學完四個任務後,系統裡只剩:

| 保留                                   | 大小                        | 含任何一張 slide 嗎 |
| -------------------------------------- | --------------------------- | ------------------- |
| G(513 × 513)與四個 $c_\tau$(各 513 維) | 約 2.1 MB,不隨 slide 數增加 | 否,只有加總結果     |
| 四個 residual scoring head             | 4,132 參數                  | 否                  |
| 8 個亞型文字向量                       | 8 × 512                     | 否,是文字           |

**跟 PathSelect 的差別**

|                              | PathSelect                             | 本方法                        |
| ---------------------------- | -------------------------------------- | ----------------------------- |
| 可訓練參數                   | 四任務共用一組 selector                | 每任務一個獨立 head + 閉式 TP |
| 學新任務時動到舊任務的參數嗎 | 會,所以需要舊資料拉住                  | 不會                          |
| 保留舊資料                   | buffer 最多 512 張 WSI 的特徵(約 3 GB) | 無                            |

「每張 slide 挑 64 個 patch」是判斷**當前這張** slide 時決定看哪些區域,判完即丟,跟 replay 無關。

## 7. 和已知方法的比較

### 7.1 T-Hard(老師提出的文字原型分派)

老師提出的想法:用文字判斷 slide 屬於哪個癌症,不需要訓練。學弟實作後稱為 T-Hard。我們依同樣的規則自己實作了一次:

$$k_\tau = \widehat{t_{\tau,1} + t_{\tau,2}}\ \ (\text{兩個亞型文字向量取平均}),\qquad \hat\tau = \arg\max_\tau \cos\big(\text{mean}(Z),\ k_\tau\big)$$

在同一組十折、接同一批 WP head 下比較:

| TP 做法       | 需要訓練嗎      | TP 正確率(四癌症平均) | CIL ACC |
| ------------- | --------------- | --------------------- | ------- |
| T-Hard        | 不需要          | 0.9154                | 0.8580  |
| 本方法(ridge) | 閉式解,不用迭代 | 0.9748                | 0.9128  |

- 老師的乘法估算成立:0.9154 × 0.9340 ≈ 0.855,實測 0.8580。
- 本方法 10 折全勝,平均高 5.5 pp。差別在於 ridge 用了該任務的訓練 slide 來學判別方向,T-Hard 只用文字。

**實作說明**

- **共同設定**:CONCH 特徵凍結;四任務依序學習(reverse:ESCA→RCC→BRCA→LUNG;forward:LUNG→BRCA→RCC→ESCA);十折。
- **TP(Task-ID Prediction)**:判斷 slide 屬於哪個癌症。
  - Oracle TP:直接使用真實任務,作為上限。
  - Ridge TP(本方法):整片 patch 平均向量 x(513 維),W = (G + γI)⁻¹C,取分數最高的任務。G、C 為累加統計量,學完一個任務即可刪除其 slide;γ = 10⁻³。
  - Balanced ridge TP:同上,但每個任務的統計量乘上 1/(該任務 slide 數),避免 slide 少的任務被忽略;γ = 10⁻⁴。
  - Prototype TP:每個任務的訓練 slide 平均向量做 k-means(k = 8),測試時判給距離最近中心所屬的任務。
  - Text-prototype TP(T-Hard):每個任務以兩個亞型文字向量的平均作為代表,判給與 slide 平均向量 cosine 最高的任務;不需訓練。
  - Organ-text TP:改用器官名稱的文字向量作為代表;不需訓練。
- **WP(Within-task Prediction)**:在判定的任務內挑 64 個 patch,平均後與兩個亞型文字比對。
  - Residual scoring head(本方法):patch 分數 = zero-shot 分數 + 小網路修正量(514 → 2 → 1,1,033 參數/任務);每任務一個,學完凍結。
  - Full-parameter head:patch 打分網路為 514 → 256 → 1(132,097 參數/任務)。
  - LoRA head:以第一個學到的任務的完整打分網路為底座,後續任務在第一層加上 rank-1 增量;rank 在 validation 上選定。
- **不拆 TP / WP 的做法**
  - Zero-shot:不判斷任務,直接以 zero-shot 分數挑 64 個 patch,與已學過的所有亞型文字比對。
  - Ridge 8-class:與 ACIL 相同的思路,以整片向量用一個 ridge 閉式解直接分到所有已學類別(t = 4 時為 8 類)。
  - QPMIL-VL:取自原論文 Tab. 1、Tab. 2;同一個 benchmark 與 backbone,但非同折重跑。

## 8. 下一步

目前 TP 是 hard assignment:一張 slide 只送給一個 head。下一步改成 **soft gating(MoE)**:TP 不確定時(例如肺和食道的分數接近),讓幾個候選任務的 head 都判一次,再依 TP 的分數加權。可能的提升上限約 2.1 pp(0.9128 → 0.9340)。
