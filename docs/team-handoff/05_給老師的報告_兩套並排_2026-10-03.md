## 1. 短版（約 450 字）

老師，報告這兩週的結果。

一、依老師的路線把 LoRA 與 MoE 這一段做完了。在每任務一個 expert、closed-form 分派器的基礎上，試了任務內兩個 expert 相加、兩種學出來的 gate、跨器官共用 head、任務間 soft gating、以文字為起點的 ridge、併入整片向量、隨機特徵等八種做法，判準都先寫好再跑，沒有一種贏過不混合的版本。這些結果我整理成分析，不當方法。

二、真正有效的改動只有一處：最後判亞型不再和文字向量比 cosine，改成和分派器同一種 closed-form ridge，用累加的統計量讀出。十折 CIL ACC 從 0.913 到 0.925，十折贏 8 到 9 折，Forgetting 也降。

三、順著這個結果，我把「每任務學一個挑證據的 head」拿掉再跑一次：只用文字相似度挑 64 個 patch，其餘不變，十折 0.921。和有 head 的 0.925 差 0.4 個百分點，十折 7 比 3，統計上分不出來。所以現在有兩套：套 A 有 head（每任務訓練 4 到 30 秒），套 B 完全不訓練、沒有 seed、每個數字閉式解。

四、外部對照改成同折。我們之前在 GPU 上用 QPMIL-VL 公開程式跑過同一組十折，這次把逐折數字接上：套 A 兩個順序各贏 9 折，平均 +5.7 與 +4.2 個百分點；套 B 也各贏 9 折。MergeSlide 要 TITAN 特徵與 3,282 張原始切片，這篇做不到同折，只放相關工作。

五、想請老師定三件事：主線用 A 還是 B；這樣的貢獻定位能不能投 ISBI（10/26）；論文名稱沿用 PathSelect 還是改。我下週出差四天，兩套的數字和圖都已經齊了，老師定了我就寫。

## 4. 兩套的差別

| | 套 A | 套 B |
|---|---|---|
| 判任務 | 整片平均向量，closed-form ridge | 同 |
| 挑證據 | 每個 patch 的分數 = 文字相似度（z-score）+ head 的修正量；四輪各 16 張，避開相似的 | 分數 = 文字相似度；其餘同 |
| 讀出 | 選出的 64 張平均、L2、補 1，累加式 ridge，在判到的器官兩類內取大 | 同 |
| 訓練 | 每任務一個 head（1,033 參數），4–30 秒；五 seed | 無；無 seed |
| 每任務要存 | head、兩個文字向量、ridge 的兩欄 | 兩個文字向量、ridge 的兩欄 |
| T = 4 儲存 | 2.16 MB | 2.15 MB |
| 每張推論 | 0.0125 秒（CPU） | 0.0117 秒 |
| 十折 CIL ACC | 0.925 ± 0.019 | 0.921 ± 0.022 |
| 對 QPMIL-VL | 贏 9／10、9／10 | 贏 9／10、9／10 |
| 故事 | 文字挑證據、學一個小修正、閉式解讀出 | 整個 CIL 不需要梯度：挑證據靠文字，判任務與判亞型都是累加統計量 |
| 會被問 | head 的 +0.4 pp 不顯著，為什麼要訓練 | 沒有任何學習，算不算 CL 方法 |
| 我的回答 | head 是 LoRA 路線留下的部件，效果在雜訊內；論文照實寫 | analytic CL（ACIL、RanPAC 一脈）是既有子領域；貢獻是把它接到 gigapixel 上：兩階段分派 +4.6 pp、文字挑證據 +1.8 pp，全部閉式解 |

我的建議：主線用 B，A 當消融表的第一列（「加上學出來的修正量 +0.4 pp，不顯著」）。理由是每個數字可重現、要解釋的機制只有一種、審稿人最可能的攻擊有數據可答。老師若要 A，數字一樣站得住，只是方法段多一段、要多答一個問題。

## 5. LoRA／MoE 這一段：試過的全部

| 做法 | 結果（t = 4 CIL ACC 或對應指標） | 判讀 |
|---|---|---|
| 任務間 soft gating（分派不取硬 argmax，按分數加權） | 與主系統相同 | 分派器已經很確定，加權沒有改變判定 |
| 跨器官共用 head | 比不用 head 還差（WP 層級） | 腫瘤證據不跨器官 |
| 任務內兩個 expert 固定相加（M3） | 0.922–0.923；小葉癌變差；逐階段漂移 | +1 pp 以內，沒過判準 |
| M3 加學出來的 gate（兩種） | 不比固定相加好 | gate 學不到東西 |
| 以文字向量為起點的 ridge | 與一般 ridge 逐張相同 | 正則化強度選定後起點無關 |
| 併入整片向量 | +0.02 pp | 無 |
| 整片 expert 換隨機特徵 | +0.2–0.35 pp，儲存 16 倍 | 不值 |
| 不挑 patch、全部平均 | 0.903（不用 head） | 挑證據有用 |
| 挑 32／64／128／256 張 | 0.920–0.921（不用 head） | 對張數不敏感 |
| 正則化強度 1e-5 … 1e-1 | 0.924／0.925／0.925／0.922／0.918 | 三個數量級內平的；選擇由 validation 的逐階段規則定，不是在 test 上挑 |

結論：在這個 benchmark 上，混合專家沒有發揮的餘地。可能的原因是四個器官的任務本來就好分（分派 0.986），混合能救的只剩分派錯的 1.4%。

## 7. MergeSlide 為什麼這篇不做同折對照

| 項目 | 查核結果 |
|---|---|
| 程式 | 公開（caodoanh2001/MergeSlide）；讀過訓練與推論程式 |
| 它的設定 | TITAN 768 維特徵、六個 TCGA 任務（含 TGCT、CESC）、自己切的十折 → 發表值與我們不可比 |
| 移植到 CONCH 的障礙 | 它微調並合併的 backbone 是 TITAN 預訓練的 slide encoder，CONCH 沒有對應物；換成替代 backbone 就不是 MergeSlide |
| 照它原設定在我們的折上跑要什麼 | TITAN 權重（本機 token 能讀 config，能否下載權重未驗證）；四 cohort 原始切片 3,282 張、約 2.6 TB（本機只有 10 張）；特徵抽取 GPU 約 5–20 小時另加讀片 7 小時 |
| 這篇的做法 | 相關工作與表註（不同特徵、不同任務、不同切分）；論文不放它的數字進主表 |
| 之後若要做 | 公司的 DGX Spark（128 GB、4 TB）放得下，ISBI 之後排；同一批原始切片也是下一篇 VQA／VLN 需要的 |

## 10. 老師可能的追問

| 老師問 | 回答 |
|---|---|
| 貢獻一句話 | 凍結病理 VLM 下的無 replay WSI 類別增量學習：判器官看整片組成、判亞型看文字挑出的證據，兩邊都是累加統計量的 closed-form 讀出；同折贏 QPMIL-VL 4–6 pp，不存任何 slide，整個系統（套 B）不需要梯度 |
| 沒有學習算 CL 嗎 | analytic CL（ACIL、RanPAC、FeCAM）是既有子領域；我們的差別是把它拆成兩階段並換輸入：8 類直接讀 0.857，先判器官再兩類內讀 0.903，輸入換成文字挑出的證據 0.921 |
| 任務是不是太好分 | 是，分派 0.986。這也是 MoE 沒有空間的原因之一；同器官多任務（例如乳癌分子分型）需要補標籤，列為下一步 |
| 和 QPMIL-VL 公平嗎 | 同一組十折切分、同指標；它用 GPU 與其公開程式，我們用 CPU；取的欄對它有利；兩序各贏 9 折 |
| 24 種順序 | t = 4 的判定與順序無關（closed-form），兩序逐張相同；逐階段 Forgetting 隨順序變，兩序都報 |
| 為什麼比有 replay 的 PathSelect 高 | PathSelect 共用一組權重會被改寫；這裡每任務的統計量加進去就不動，剩下的只有分派 |
| MergeSlide 呢 | 不同特徵、不同任務、不同切分，不可比；同折要 2.6 TB 原始切片與 TITAN，ISBI 之後在 Spark 做 |
| head 有什麼用 | 成本 3%、與順序無關；對 CIL ACC +0.4 pp，不顯著。論文照實寫 |
| 四輪挑片有什麼用 | 和一次挑 64 差 0.15 pp，不顯著；保留是因為預先註冊，消融表寫明 |

## 11. 約法三章

| 代號 | 意思 |

| 套 A | 程式裡的 FINAL-A：closed-form 分派 + 每任務 head 四輪挑證據 + closed-form 讀出；五 seed |
