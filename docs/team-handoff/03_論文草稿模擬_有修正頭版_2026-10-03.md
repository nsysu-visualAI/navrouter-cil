# 論文草稿模擬（套 A 版）：文字導引證據選擇、每任務低秩修正與累加式閉式讀出的無重播 WSI 類別增量學習

## 題目

PathSelect：Text-Guided Evidence Selection with Analytic Routing and Readout for Replay-Free Class-Incremental Whole-Slide Image Classification

## 摘要（約 180 字）

全切片影像（WSI）的類別增量學習要在不保存舊切片的前提下，持續加入新的器官與亞型。我們提出 PathSelect：影像與文字編碼器全部凍結，判斷器官用整片平均特徵的閉式 ridge 分派器，判斷亞型用文字導引挑出的 64 個 patch 證據，再以同樣的累加統計量做閉式讀出；每個任務另學一個 1,033 參數的低秩修正頭調整挑證據的分數。所有判斷只依賴累加的二階統計量，不存任何切片，新任務加入只需累加統計量並訓練一個小頭，t = 4 的判定與任務順序無關。在四任務 TCGA 基準（ESCA、RCC、BRCA、NSCLC）十折交叉驗證下，CIL 準確率 0.925，較同一組切分重跑的 QPMIL-VL 高 4.2 到 5.7 個百分點，十折中贏 9 折，Forgetting 降為三分之一。消融顯示增益主要來自兩階段分派、文字挑證據與閉式讀出；學出來的修正頭貢獻 +0.4 pp，未達顯著。

## 1. 緒論

病理 WSI 的分類任務會隨新的器官、新的亞型持續出現；重新訓練整個模型不可行，保存舊切片又受隱私與儲存限制。既有的 WSI 類別增量方法（ConSlide、QPMIL-VL）依賴 replay 緩衝或 prompt pool 與可訓練的聚合器，而通用 CL 文獻中的 analytic CL（ACIL、RanPAC、FeCAM）證明在凍結特徵上，閉式更新的線性讀出可以完全避免遺忘。但 WSI 的困難在於輸入不是一個向量：一張切片有數千個 patch，直接平均會把腫瘤證據淹沒在背景組織裡。

我們的觀察是：判器官與判亞型需要的證據不同。器官資訊在整片的組織組成裡，整片平均就夠；亞型資訊在少數腫瘤 patch 裡，需要先挑出來。據此設計兩階段、同一種機制的系統：先用整片平均向量做閉式分派，再在該任務的兩類內用挑出的證據做閉式讀出；挑證據以該任務的類別文字相似度為基礎，每任務另學一個小修正頭。

貢獻：

1. 一個無重播的 WSI 類別增量框架：分派與讀出都是累加統計量的閉式解，不存切片，t = 4 的判定與任務順序無關；四任務 TCGA 十折 CIL 準確率 0.925，同折對照贏 QPMIL-VL 9/10 折。
2. 文字導引的證據選擇與每任務低秩修正頭：以凍結 VLM 的類別文字相似度挑 patch，每任務以 1,033 參數的修正頭微調分數；修正頭不依賴先前任務、儲存為完整 expert 的 3%。
3. 系統性分析：在此基準上，兩階段分派（+4.6 pp）、文字挑證據（+1.8 pp）、閉式讀出（+1.2 pp）各自的貢獻；八種專家混合設計均無增益；修正頭的 +0.4 pp 未達顯著；小葉癌是所有設定下最弱的類別。

## 2. 相關工作（要點）

| 線 | 代表 | 與本文的差別 |
|---|---|---|
| WSI 持續學習 | ConSlide（replay）、QPMIL-VL（prompt pool、可訓練聚合器）、MergeSlide（合併微調的 TITAN slide encoder） | 本文不 replay、不訓練聚合器、不合併權重；讀出為閉式解 |
| analytic CL | ACIL、RanPAC、FeCAM | 它們的輸入是單一向量；本文把輸入換成文字挑出的證據，並拆成分派與讀出兩階段 |
| 文字導引的 patch 選擇 | zero-shot top-K（ZeroSlide 類） | 本文在選出的證據上做閉式讀出而非 cosine 投票，並加每任務修正頭 |

## 3. 方法

### 3.1 凍結嵌入

CONCH 影像編碼器把每張切片編成 Z ∈ R^{N×512}；文字編碼器把每個類別的描述編成 t_c ∈ R^{512}。兩者全程凍結。

### 3.2 閉式分派（判器官）

x = [L2(mean(Z)); 1] ∈ R^{513}。累加 G = Σ x xᵀ、C = Σ x yᵀ（y 為任務 one-hot），W_TP = (G + γI)⁻¹C，τ̂ = argmax xᵀW_TP。新任務只需把它的切片加進 G 並新增 C 的一欄。

### 3.3 文字導引證據選擇與修正頭（判亞型的輸入）

對 patch i，s0_i = z-score(max_c cos(z_i, t_c))，c 取 τ̂ 的兩類。修正頭 h_τ 輸入 [z_i; max cos; entropy]，輸出 g_i；s_i = s0_i + g_i。依 s_i 分四輪各取 16 個 patch，每輪對已選 patch 施加冗餘懲罰 λ = 1.5。選出的 64 個 patch 平均、L2、補 1 得 v̄ ∈ R^{513}。h_τ 以該任務訓練切片的類別標籤、cosine 交叉熵訓練 5 個 epoch，之後凍結。

### 3.4 累加式閉式讀出（判亞型）

累加 A = Σ v̄ v̄ᵀ（所有任務共用）、B = Σ v̄ yᵀ（y 為 2T 類 one-hot，每任務新增兩欄），W = (A + γI)⁻¹B。推論時只看 τ̂ 的兩欄，取大者為亞型。γ = 10⁻³，以逐階段 validation 規則選定。

### 3.5 持續學習流程與儲存

學任務 τ：訓練 h_τ → 用 h_τ 挑證據、累加 G、C、A、B → 刪除切片。共用儲存為兩個 513 × 513 矩陣（約 2.1 MB，不隨任務增長）；每任務增加 h_τ（1,033 參數）、兩個文字向量與 B 的兩欄，約 14 KB。

## 4. 實驗

### 4.1 設定

四任務 TCGA（ESCA：腺癌／鱗癌；RCC：透明細胞／乳突；BRCA：導管／小葉；NSCLC：腺癌／鱗癌），QPMIL-VL 釋出的十折切分；兩種順序（reverse：ESCA→RCC→BRCA→NSCLC；paper：相反）。指標：CIL ACC（不告訴任務、已見全部類別）、Masked ACC、Forgetting、BWT。本文方法在 Mac CPU 跑；QPMIL-VL 以其公開程式在同一組十折於 GPU 重跑。修正頭報五個 seed 平均。

### 4.2 主結果（t = 4，十折）

| 系統 | CIL ACC | Masked ACC | Forgetting rev／paper | 每任務儲存 |
|---|---|---|---|---|
| zero-shot top-64 + cosine（不訓練、不分派） | 0.827 ± 0.031 | 0.904 | 0.070／0.025 | 0 |
| 8 類閉式 ridge（整片平均） | 0.857 ± 0.029 | 0.924 | 0.091／0.010 | 4 KB |
| QPMIL-VL（同折重跑） | 0.868 ± 0.046／0.884 ± 0.033 | 0.935／0.926† | 0.064／0.038 | — |
| 分派 + 修正頭挑證據 + cosine 讀出 | 0.913 ± 0.022 | 0.930 | 0.022／0.004 | 10 KB |
| 分派 + 文字挑證據 + 閉式讀出（無修正頭） | 0.921 ± 0.022 | 0.940 | 0.023／0.008 | 10 KB |
| **PathSelect（本文）** | **0.925 ± 0.019** | **0.947** | 0.021／0.007 | 14 KB |

† 告訴任務定義。發表值 0.859／0.890。

逐折配對：PathSelect 對 QPMIL-VL reverse +0.057（9/10，p = 0.02）、paper +0.042（9/10，p = 0.02）；對 cosine 讀出 +0.012（8/10，CI [+0.006, +0.019]）；對無修正頭 +0.004（7/10，p = 0.34，CI 跨 0）。

### 4.3 消融：一階一階加

| 設定（全部閉式解） | CIL ACC | 增量 |
|---|---|---|
| 8 類直接讀，整片平均 | 0.857 | — |
| 先分派，再兩類內讀，整片平均 | 0.903 | +4.6 |
| 輸入換成文字挑出的 64 張 | 0.921 | +1.8 |
| 加修正頭（本文） | 0.925 | +0.4（n.s.） |

其他：四輪對一次 top-64 +0.15 pp（n.s.）；K = 32–256 差 ≤ 0.1 pp；γ 在 10⁻⁵–10⁻³ 平（0.924–0.925）。

### 4.4 專家混合的負結果

任務間 soft gating、跨器官共用修正頭、任務內兩個 expert 相加（+ 兩種 gate）、以文字為起點的 ridge、併入整片向量、隨機特徵：無一通過預先寫定的判準（最多 +1 pp 且伴隨逐階段漂移或 16 倍儲存）。

### 4.5 逐類別與限制

小葉癌 73.5%（其餘七類 92–98%），比 cosine 讀出再低 4.8 pp；四個器官的任務本來好分（分派 0.986），專家混合沒有發揮空間可能與此有關。

## 5. 結論

不存切片、只累加統計量的兩階段閉式系統，在 WSI 類別增量基準上超過需要 prompt pool 與可訓練聚合器的方法。增益來自分派、文字挑證據與閉式讀出；每任務的修正頭成本低但貢獻在雜訊內。
