## 1. 結論：還剩哪些要跑、為什麼現在跑

FINAL 的數字已經齊了，剩下的程式工作不是改方法，是讓主表站得住：外部對照目前是「發表值」（不同折、不同切分），審稿人和老師第一個會問這個。另外定稿表格裡的消融列 Cursor 只抽查過，要全量重算一次才能進論文。這些全部可以從既有快取和既有輸出算，Mac 就夠，所以一次打包成 EXT-1 今晚跑。

| 部分 | 做什麼 | 為什麼需要 | 機器 | 預估 |
|---|---|---|---|---|
| A | 找出我們之前用 QPMIL-VL 公開程式在同一組十折上跑的逐折輸出，驗證 fold 一致，匯入後與 FINAL 逐折配對 | 主表的 QPMIL-VL 從發表值變成同折數字，可以報「贏幾折」 | Mac | 1 小時內（找檔案為主） |
| B | MergeSlide 移植到我們的 CONCH 特徵與十折，先計時再決定在哪跑 | 第二個不 replay 的對照，且是 2025 年底的方法；只改特徵維度、文字向量、任務定義、切分四件事 | Mac 先估時間；超過 12 小時等你指定 GPU | 估時 1 小時；全跑 Mac 上可能 3–20 小時 |
| C | FINAL_RESULTS.md 與 moe0–moe4 會進論文的每一列，十折兩序全量重算，逐格比對 | 之前只抽查；論文表格每一格都要能回溯到一次完整的跑 | Mac | 2–4 小時 |
| D | 配對統計（贏幾折、符號檢定、bootstrap CI）、推論與訓練成本、γ 敏感度、混淆矩陣 | 主表與補充材料要用，目前只有平均值 | Mac | 1–2 小時 |

不跑的東西與理由：

| 項目 | 不跑的理由 |

| 再試新的 MoE／gate 變體 | MOE-0 到 MOE-4 已有六種負結果，判準全部沒過；沒有新數據支持再開一輪 |

| 換更難的 benchmark（同器官多任務） | 要新標籤，不是這篇的範圍 |

## 2. 關於 MergeSlide 的查證（寫指令前查過）

| 項目 | 查到的 |
|---|---|
| 論文 | MergeSlide: Continual Model Merging and Task-to-Class Prompt-Aligned Inference for Lifelong Learning on Whole Slide Images（arXiv 2511.13099；WACV 2026 有海報頁） |
| 程式 | 公開：github.com/caodoanh2001/MergeSlide |

## 5. 約法三章（本頁代號）

| 代號 | 意思 |
|---|---|
| EXT-1 | 本批次：外部對照同折化與定稿表格全量重算 |
| FINAL | 定案系統：AR TP + head 四輪 + ridge readout γ = 1e-3 |
| AR | 任務辨識用的 closed-form ridge（Σxxᵀ 累加） |
| head | 每任務的殘差評分頭（I6，r = 2，1,033 參數） |
| ridge readout | 最後判亞型的 closed-form ridge，只在 τ̂ 的兩類裡判 |
| PREREG-21 | 本批次預先寫死的規則與查核 |
| K6／K7／K8 | 折一致性／重算一致性／MergeSlide 健全性 |
| 同折配對 | 同一 fold、同一序兩個系統各一個數字，逐折比，報贏的折數與符號檢定 |
| Masked ACC（Table 1 定義） | 主系統沿用的定義；FINAL 之前用「告訴任務」定義，兩者在 C3 都算，主表統一用前者 |
| QPMIL-VL | 外部對照一：釋出四任務切分的方法；當年我們曾在 GPU 上用其公開程式跑過同一組十折 |
| MergeSlide | 外部對照二：不 replay、合併權重的方法（arXiv 2511.13099），程式公開，原用 TITAN 特徵 |
| navipath | 舊 repo，含 QPMIL-VL 相關程式；只從它找數字，不把程式帶進 navrouter-cil |
| done 標記 | 每個 (order, fold) 跑完寫一個檔，重跑自動跳過 |
