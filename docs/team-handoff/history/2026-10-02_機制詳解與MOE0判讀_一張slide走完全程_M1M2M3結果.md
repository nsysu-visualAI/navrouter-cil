# NavRouter-CIL-02：機制詳解與 MOE-0 判讀（2026-10-02）

與其他文件的關係：接在 MoE 規劃之後。本頁的機制描述全部以 Cursor 的 `outputs/navcil/mac/AUDIT_wp.md`（逐行對過程式）為準；數字出自 `REPORT_moe0.md`（分支 moe-0，commit d56cbd1，十折，test，t = 4）。

注意：本頁寫於 10/2，當時主系統最後一步仍是「和文字比 cosine」（0.9128）。之後 MOE-2～MOE-4 把讀出改成閉式 ridge（0.925），見後續文件。

## 0. 結論

| # | 結論 |
|---|---|
| 1 | 現在的系統是兩段：TP 用整片平均向量判器官；WP 用該器官的 head 挑 64 個 patch，平均後和兩個亞型的文字比 |
| 2 | head 不直接判亞型。它只給每個 patch 一個分數，決定「看哪裡」 |
| 3 | 訓練和推論用 head 分數的方式不同：訓練時分數當「權重」，推論時分數當「入選名次」 |
| 4 | M1（soft gating）沒有效果，原因是結構性的：每個 head 只會在自己的兩類裡選一個，不會說「這不是我的片子」 |
| 5 | M2（跨器官共用 head）不成立：肺的 head 用在食道，比完全不用 head 還差 19 pp |
| 6 | M3（整片統計＋局部證據）有正的訊號：兩者錯的片子只有一半重疊，最簡單的相加就讓 CIL ACC 從 0.9128 到 0.9226（十折贏 8 折） |
| 7 | M3 目前只拿到可用空間的三成左右，而且還不能排除「只是 ensemble」 |

## 2. TP：怎麼判器官

| 項目 | 內容 |
|---|---|
| 輸入 | 整片所有 patch 的平均向量 x（513 維：512 維平均後正規化，加一個常數 1） |
| 目標 | 自己任務的那一欄輸出 1，其他任務的欄輸出 0 |
| 解法 | W = (G + γI)⁻¹ C，γ = 0.001 |
| G | 所有訓練 slide 的 x xᵀ 加總，513 × 513 |
| C | 每個任務一欄，該任務所有訓練 slide 的 x 加總，513 × 4 |
| 推論 | x 乘 W 得 4 個分數，取最大 |

（程式裡 TP 的 G、C 叫 A、B。報告為了不和 LoRA 的 A、B 撞名改成 G、C。）

為什麼學新任務不需要舊 slide：G 和 C 都是加總。學第 t 個任務時，只要把這個任務的 x xᵀ 加進 G、把這個任務的 x 總和補成 C 的新一欄，再重解一次 W。結果和「四個任務的 slide 全部拿來一次解」相同。

為什麼比「看和哪個器官的平均最像」準：各器官的平均向量裡，大部分成分是共有的（染色、間質、背景）。(G + γI)⁻¹ 這一步會把共有方向壓低。實測：肺被判成食道的張數，用群中心是 39 張，用 ridge 是 2 張。

| 任務 | test 張數（十折合計） | TP 正確率 |
|---|---|---|
| 食道 | 150 | 0.934 |
| 腎 | 768 | 0.991 |
| 乳房 | 952 | 0.987 |
| 肺 | 965 | 0.987 |
| 四任務等權平均 | — | 0.975 |
| 全部 slide 合計 | 2,835 | 0.986（錯 41 張） |

## 3. WP：怎麼判亞型

### 3.1 s0：不用訓練的起始分數

| 步驟 | 內容 |
|---|---|
| 文字向量怎麼來 | 每個亞型有 3–5 個同義名，各套 22 個模板（例如「an H&E stained image of …」），共 66–110 句。每句過 text encoder，平均後正規化。事先算好存檔 |
| patch 分數 | patch 與該任務兩個亞型文字各算 cosine，取較大的那個 |
| s0 | 上面的分數在這張 slide 的所有 patch 內做 z-score |

s0 的意思是「這個 patch 像不像這個任務的腫瘤」，不管像的是哪一個亞型。

### 3.2 head：在 s0 上加修正量 g

| 維度 | 內容 |
|---|---|
| 1–512 | patch 的原始特徵（沒有正規化） |
| 513 | 與兩個亞型文字的 cosine 取較大者 |
| 514 | 兩個 cosine 做 softmax 後的 entropy（實測幾乎是常數 0.673–0.693） |

| 層 | 運算 | 輸出 shape | 參數量 |
|---|---|---|---|
| 第一層 | A u + b1，A 是 2 × 514 | 2 | 1,028 + 2 |
| 非線性 | GELU | 2 | 0 |
| 第二層 | 乘 w2 後相加，再加 b2 | 1（就是 g） | 2 + 1 |
| 合計 | | | 1,033 |

| 細節 | 說明 |
|---|---|
| 初始時 g = 0 | w2 和 b2 初始為 0，所以訓練開始時 s = s0，系統等於 zero-shot |
| b2 沒有作用 | 加在每個 patch 分數上的同一個常數，排名不受影響。實際上有作用的參數是 1,032 個 |

實例：這張 slide 最後選出的 64 個 patch 裡，有 46 個原本不在 s0 的前 64 名。在肺這個任務上，head 把「看哪裡」改掉了七成。

### 3.3 挑 64 個 patch：四輪，每輪 16 個

| 步驟 | 內容 |
|---|---|
| 第 1 輪 | 取分數最高的 16 個 |
| 第 2–4 輪 | 每個還沒選的 patch，分數扣掉「1.5 × 它和已選 patch 的最大 cosine」，再取最高的 16 個 |
| 輪與輪之間 | head 不重算；變的只有「已選了誰」 |

1.5 這個係數是在 fold 1 的 validation 上選的，之後十折固定。

### 3.5 訓練：head 的梯度從哪裡來

| 步驟 | 內容 |
|---|---|
| 1 | 算 s = s0 + g |
| 2 | 照 s 一次取前 64（不傳梯度，沒有扣分） |
| 3 | 對這 64 個的分數做 softmax，得到權重 w |
| 4 | 用 w 對 64 個 patch 加權平均，正規化 |
| 5 | 與兩個亞型文字算 cosine，乘上 56.35（encoder 自帶的 logit scale），算 cross-entropy |
| 6 | 梯度只經過第 3 步的 w 回到 g |

設定：Adam，lr 5e-4，5 個 epoch，只用當前任務的 train split；seed 42。

### 3.6 訓練與推論的落差

| | 選 patch | 合成 slide 向量 | head 的分數被當成 |
|---|---|---|---|
| 訓練 | 一次取前 64，不扣分 | softmax 加權 | 權重 |
| 推論 | 四輪各 16，有扣分 | 等權平均 | 入選名次 |

### 3.7 head 在每個任務幫了多少（cosine 讀出下）

| 任務 | 只用 s0 | 用自己的 head | head 的貢獻 |
|---|---|---|---|
| 食道 | 0.955 | 0.961 | +0.6 pp |
| 腎 | 0.942 | 0.961 | +2.0 pp |
| 乳房 | 0.806 | 0.918 | +11.2 pp |
| 肺 | 0.884 | 0.896 | +1.2 pp |
| 四任務等權 | 0.897 | 0.934 | +3.7 pp |

head 的貢獻幾乎都在乳房。（注意：這是 cosine 讀出下的數字；改成閉式讀出後，head 的整體貢獻降到 +0.4 pp，見 EXT-1／EXT-2。）

## 5. 三個 MoE 設計：原理、結果、為什麼

### 5.1 M1：任務層級的 soft gating

| 項目 | 內容 |
|---|---|
| 做法 | 4 個任務分數除以 T 後做 softmax 得任務權重 π；四個 head 都跑；類別 c 的分數 = π × q |
| 結果 | 2,835 張只改了 1 張 |
| 原因 1 | π 幾乎都是 1 和 0：實例的任務分數 0.028、0.023、−0.123、1.072，T = 0.1 時肺的權重 0.9999 |
| 原因 2 | head 不會說「不是我的」：每個 head 只能在自己的兩類裡分配機率，混進來只會多一個有把握的錯答案 |

### 5.2 M2：跨器官共用 head

結果（列 = 用誰的 head，欄 = 片子屬於哪個任務；告訴正確任務與文字，只換 head 權重）：

| head | 食道 | 腎 | 乳房 | 肺 |
|---|---|---|---|---|
| 食道的 | **0.961** | 0.936 | 0.860 | 0.847 |
| 腎的 | 0.935 | **0.961** | 0.855 | 0.872 |
| 乳房的 | 0.942 | 0.944 | **0.918** | 0.857 |
| 肺的 | 0.764 | 0.932 | 0.880 | **0.896** |
| 不用 head | 0.955 | 0.942 | 0.806 | 0.884 |

| 觀察 | 意思 |
|---|---|
| 肺的 head 用在食道：0.764，比不用 head（0.955）低 19 pp | 假設裡最該能共用的一對，反而最差 |
| 肺這一欄，別的 head 全部比不用 head 差 | 肺需要的修正，別的任務給不了 |
| 乳房這一欄，別的 head 全部比不用 head 好，但都不如自己的 | 有一部分修正是通用的，但不夠 |

結論：head 學到的修正量是任務專屬的。M2 不做。這張表支持「每任務一個 head」這個設計。

### 5.3 M3：整片統計 expert 與局部證據 expert

| | 局部證據 expert | 整片統計 expert |
|---|---|---|
| 就是 | 現有的 head 那條路 | 一個 ridge 分類器，直接用整片平均向量分 8 類 |
| 看什麼 | 挑出來的 64 個 patch | 全部 patch 的平均 |
| 怎麼學 | 每任務訓練 1,033 個參數 | closed-form，和 TP 用同一個 x、同一個 G |
| 輸出 | 兩個亞型的 cosine 差 d_a | 兩個亞型的 ridge 分數差 d_b |

錯誤重疊（告訴任務，十折合計）：

| 任務 | 都對 | 只有局部對 | 只有整片對 | 都錯 | 局部正確率 | 整片正確率 |
|---|---|---|---|---|---|---|
| 食道 | 135 | 9 | 6 | 0 | 0.960 | 0.940 |
| 腎 | 723 | 15 | 12 | 18 | 0.961 | 0.957 |
| 乳房 | 817 | 57 | 31 | 47 | 0.918 | 0.891 |
| 肺 | 826 | 38 | 52 | 49 | 0.895 | 0.910 |
| 合計 | 2,501 | 119 | 101 | 114 | 0.924 | 0.918 |

局部錯了 215 張，其中 101 張整片是對的；肺是整片較準、乳房是局部較準。

最簡單的混合：融合分數 = d_a ÷ σ_a + β × d_b ÷ σ_b（不能減平均：分數差的 0 就是兩類分界，減平均會把分界移走；證據是減了平均後 β = 0 結果從 0.934 掉到 0.897）。

| β | validation | test Masked ACC | test CIL ACC |
|---|---|---|---|
| 0（等於主系統） | 0.9194 | 0.9340 | 0.9128 |
| 0.5 | 0.9317 | 0.9439 | 0.9231 |
| 1.0（validation 選中） | 0.9402 | 0.9448 | 0.9226 |
| 2.0 | 0.9393 | 0.9462 | 0.9243 |

β = 1 對主系統：CIL +0.98 pp，贏 8/10，Wilcoxon p 0.020。對 β 不敏感。增益 1.09 pp，可用空間 3.51 pp，只拿到三成。

門檻記為未通過的原因：指令把正規化寫成「減平均再除標準差」，照字面是 −1.56 pp，記入 AMENDMENT-5。

（後續：MOE-1 證實 M3 的增益大半是 ensemble 性質且逐階段漂移，M3 加 gate 也沒更好；真正通過判準的是把讀出整個換成閉式 ridge，見 MOE-2～MOE-4。）

## 7. 老師可能的追問

| 問題 | 回答 |
|---|---|
| head 到底在分類什麼 | 它不分類。它給每個 patch 一個分數，決定挑哪 64 個 |
| s0 是什麼 | patch 與該任務兩個亞型文字的 cosine 取較大者，在 slide 內做 z-score |
| 挑 patch 不可微，怎麼訓練 | 選取本身不傳梯度。梯度經過選中的 64 個 patch 的 softmax 權重回到 head |
| 為什麼四輪 | 讓 64 個分散在不同區域。消融顯示一次取 64 差不多 |
| 1,033 怎麼算 | 2 × 514 + 2 + 2 + 1 |
| 這算 LoRA 嗎 | 形式上是低秩（中間只有 2 維），但它是加在 zero-shot 分數上的殘差，不是加在某個預訓練權重矩陣上的增量 |
| soft gating 為什麼沒用 | TP 的權重幾乎都是 0 和 1；每個 head 只會在自己的兩類裡選 |
| 食道和肺都是腺癌對鱗癌，為什麼不共用 | 實測互換後比不用 head 還差 |
| 整片統計 expert 和 TP 不是同一個東西嗎 | 同一份統計量、同一種解法，目標不同 |

## 8. 10/2 修正的先前說法

| 項目 | 先前的說法 | 稽核後的正確內容 |
|---|---|---|
| head 輸入的第 513–514 維 | 與兩個亞型文字的相似度各一維 | 第 513 維是兩個 cosine 的較大者；第 514 維是 entropy |

| 參數 | 1,033 個都有作用 | b2 沒有作用，實際 1,032 個 |
| TP 正確率 | 0.986 | 0.986 是全部 slide 合計；四任務等權是 0.975 |

## 10. 本頁代號

| 代號 | 意思 |
|---|---|
| TP／WP | 判器官／判亞型 |
| Z、x | 一張 slide 所有 patch 的特徵（N × 512）；整片平均向量（513） |
| G、C、W | TP 的累加統計量與解出的權重（程式裡叫 A、B、W） |
| s0、g、s、u | 起始分數；修正量；最終分數；head 輸入（514 維） |
| A、b1、w2、b2 | head 的四組參數（這裡的 A 是 head 第一層，和 ridge 無關） |
| 扣分係數 | 選 patch 時扣掉與已選者相似度的倍數（1.5）；程式裡叫 λ |
| β | 融合時整片統計 expert 的權重 |
| d_a、d_b、σ_a、σ_b | 兩個 expert 的兩類分數差；其在 validation 上的標準差 |
| M1、M2、M3 | soft gating；跨器官共用 head；整片統計與局部證據兩個 expert 的混合 |
