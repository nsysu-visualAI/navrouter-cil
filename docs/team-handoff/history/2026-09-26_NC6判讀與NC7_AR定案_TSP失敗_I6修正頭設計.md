## 2. 機制鏈：AR 到底修好了什麼

| 系統 | 做法 | 肺→食道 | 食道→肺 | TP micro | CIL |
|---|---|---|---|---|---|
| R2 | 每任務一個平均向量，cosine | 65 | 4 | 0.942 | 0.890 |
| 白化後的 R2 | 先依所有訓練片子的統計量重新加權，再做 R2 | 74 | 1 | 0.953 | 0.905 |
| AR | 判別式：用標籤直接解出邊界，所有訓練片子一起算 | 2 | 6 | 0.986 | 0.918 |
| AR-bal | 同 AR，但每個任務的權重拉成一樣 | 26–55（γ 越大越多） | — | 0.956–0.975 | 0.904–0.921 |

| 步驟 | 看到的 | 代表什麼 |
|---|---|---|
| 1 | 白化讓整體 TP 從 0.942 升到 0.953，但肺→食道從 65 變 74 | 重新加權對其他任務有幫助，但沒修好肺與食道 |
| 2 | 判別式 AR 把肺→食道降到 2，食道→肺是 6（全是食道鱗癌） | 修好肺→食道的是判別式的邊界 |
| 3 | 把任務權重拉平（AR-bal），肺→食道又回到 26–55 | AR 的邊界偏向訓練片子多的任務 |
| 4 | 模稜兩可的鱗癌片子始終存在 | 肺鱗癌與食道鱗癌在表徵上仍然分不乾淨 |

AR 的進步有兩個來源：判別式邊界本身（AR-bal 在不偏向大任務的情況下 CIL 仍有 0.904–0.921，高於 R2 的 0.890），以及對大任務的偏好。論文裡要把 AR 和 AR-bal 並列。

## 3. TSP 為什麼沒過（在「狀態」這一步就失敗）

| 步驟 | 內容 |
|---|---|
| 介入 | 用類別文字算出組織型方向（例如「肺鱗癌」減「肺腺癌」），從特徵裡拿掉 |
| 預期的狀態 | 肺鱗癌和食道鱗癌變得比較不像 |
| 實際的狀態 | 兩類平均向量的 cosine 從 0.871 升到 0.883：反而更像 |
| 行為 | 肺→食道 37 張，沒有改善 |
| 指標 | R3＋TSP 0.890，比 R3 的 0.899 還低；AR＋TSP 和 AR 一樣 |

文字端算出的方向，和影像特徵裡真正區分兩類的方向不重合。

## 6. 創新的現況（老實版）

| 項目 | 狀態 |
|---|---|
| router 那一側 | 12 個候選都沒贏當時的基準。AR 本身是已知的解析式持續學習（ACIL、DS-AL、Any-SSR 一類） |
| 能主張的發現 | (1) WSI CIL 的瓶頸在分派；(2) 分派錯誤集中在跨器官的同一種組織型；(3) 改輸入沒用，改比法有用；(4) 判別式 router 的進步有一部分來自任務大小的偏好 |
| LoRA 那一側 | I7 沒過；I6 待測（NC-7） |
| I6 為什麼值得做 | LoRA 要拿第一個任務的完整 expert 當底座：底座 528 KB，且結果受順序影響。I6 改用 VLM 的 zero-shot 分數當底座，每任務只學一個很小的低秩修正；整個系統在 t = 4 與順序無關 |

## 7. NC-7 的 I6 設計（PREREG-7，摘要；這就是後來的「修正頭」）

| 項目 | 內容 |
|---|---|
| 形式 | score(x) = s0(x) + g(u)。s0 = 該任務 2 類文字對 patch 的最大 cosine，在 slide 內 z-score，不訓練。u = [Z ; text_nav_feats(Z, f_task)]（514 維）。g(u) = w2ᵀ GELU(A u + b1) + b2，A ∈ R^{r×514}、b1 ∈ R^r、w2 ∈ R^r（初始化 0）、b2 ∈ R。每任務參數 516r + 1；r ∈ {1, 2, 3} |
| 訓練 | 與 L 線 v2 相同的 train_selector 設定（seed 42、5 epochs、lr 5e-4、wd 1e-4）；每折每任務訓練一次，不分順序 |
| 評估 | 四輪 K=64、每輪 16、λ*=1.5，所選 patch 等權平均後正規化，凍結 CONCH 頭 |
| 選 r | 十折 validation 的四任務平均 WP ≥ L0 − 0.01 的 r 中取最小者 |
| I6-pass | r* 符合，且 test WP ≥ 0.9299，每任務參數 ≤ 2,053 |
| D3 | AR（γ = 0.001）＋ I6(r*)，兩序 ACC、Masked ACC、Forgetting、BWT、逐階段；與 D1 逐折相減 |
| B 段 | 分派不確定時轉交：依 AR 分數 margin 由低到高轉交 {0, 1, 2, 5, 10}% 給病理醫師，報剩下片子的 ACC |

## 9. 本頁代號

| 代號 | 意思 |
|---|---|
| AR | 解析式 router：用標籤解出的線性邊界，封閉解一次算出 |
| AR-bal | AR 加上每任務權重相同 |
| 白化 | 依所有訓練片子的統計量把特徵重新加權；不用標籤 |
| TSP | 用類別文字算出組織型方向，從特徵裡拿掉再分派；沒過 |
| D1、D2、D3 | AR＋LoRA r=2；AR＋完整 expert；AR＋I6 |
| I6 | 以 zero-shot 分數為底座、每任務只學一個很小的低秩修正的 expert（修正頭） |
| s0、g | I6 裡的 zero-shot 分數；每任務學的低秩修正 |
| 轉交 | router 沒把握的片子交給病理醫師 |
