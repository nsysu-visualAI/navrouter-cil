## 2. 機制鏈：從假設到結論

| 步驟 | 內容 | 數字 |
|---|---|---|
| 假設 | 肺被派到食道，是因為兩個器官有同一種組織型（鱗癌），腫瘤區讓兩者看起來像 | — |

| 指標 | 9 個背景候選的 CIL 都沒贏基準 | 最好 +0.001／−0.002 |

## 3. 決定與修改

| 項目 | 原本 | 改成 | 理由 |
|---|---|---|---|
| 主 router | R3(k=8)：每任務 8 個平均向量 | AR：共用一個統計矩陣的封閉解 | validation CIL 0.9166 對 0.8942，高 2.2 pp；依 validation 決定，不是依 test |
| 儲存規則 | 每任務 ≤ 16 KB | 不存任何 slide 或 patch 特徵；統計量可存，逐項揭露大小 | AR 共用一個 513 × 513 矩陣（fp32 約 1 MB），是所有訓練片子的二階統計量，無法還原單張片子；FeCAM 每類存 512 × 512 共變異，被接受為 exemplar-free |
| 背景分派 | NC-5 主測 | 停止 | 改輸入沒幫助，問題在比法 |
| 創新的位置 | router 看的輸入 | (1) router 的比法裡能不能加入 VLM 的資訊（TSP）；(2) LoRA expert 不再依賴第一個任務（I6） | 見第 4 節 |

## 4. 這對創新代表什麼

| 項目 | 內容 |
|---|---|
| 能主張的發現 | (1) WSI CIL 的瓶頸在分派；(2) 分派錯誤集中在跨器官的同一種組織型（肺鱗癌、食道鱗癌）；(3) 原因在比法，不在輸入 |
| 已知做法（要引用） | AR 這類封閉解 router（Any-SSR、RanPAC、ACIL）；每任務一個專家、學完凍結 |
| 剩下的缺口 | 上限 0.940、現在 0.917，差 2.3 pp；主要在食道（任務辨識 0.934）。食道只佔訓練資料 5%，封閉解會偏向大任務 |
| NC-6 的創新候選 | TSP（文字引導的組織型方向移除）：用 CONCH 的類別文字找出組織型方向（例如「肺鱗癌」減「肺腺癌」），從特徵裡拿掉再分派 |
| NC-7 的創新候選 | I6（不依賴第一個任務的 LoRA expert）：用 VLM 的 zero-shot 分數當底座，保留 LoRA 的省參數，又讓整個系統與順序無關 |

## 6. NC-6 設計（PREREG-6，摘要）

| 段 | 內容 |
|---|---|
| A | AR 的兩個調整：γ 候選 {1e-4, 1e-3, 1e-2, 1e-1}；AR-bal（依任務樣本數加權 w_j = 1/n_j）。{AR, AR-bal} × 四個 γ 以十折 validation 選定；選出者做依序累加 vs 一次解的一致性檢查（W 最大差 < 1e-4） |
| B | TSP：用類別文字算出要拿掉的方向（U_diff = 每任務兩類文字差；U_all = 全部類別文字），投影 P = I − UUᵀ 後再分派。判準 TSP-pass-1（R3＋TSP 用 16 KB 追上 AR）、TSP-pass-2（AR＋TSP 比 AR ≥ +0.01 且贏 ≥ 7 折） |
| C | 機制檢查：C1 比法對了之後輸入還重要嗎（背景向量、腫瘤半向量）；C2 γ 趨勢；C3 是「重新加權」還是「判別訓練」（白化後做 R2） |
| D | 新主系統 D1 = AR＋L1(r=2)、D2 = AR＋L0：兩序 ACC、Masked ACC、Forgetting、BWT、逐階段、儲存分項 |

## 8. 本頁代號

| 代號 | 意思 |
|---|---|
| R3(k=8) | 舊主 router：每任務存 8 個平均向量，用 cosine 找最像的 |
| R2 | 每任務存 1 個平均向量的 router |
| AR | 解析式 router：依所有訓練片子的共變異重新加權後做線性判斷，用封閉解一次算出；新主 router。10/8 匯報裡叫「閉式 ridge 分派器」 |
| AR-bal | AR 加上「依任務樣本數加權」 |
| γ | AR 的正則化強度 |
| TSP | 文字引導的組織型方向移除 |
| LIN8 | 不用 expert、不用 router 的 8 類線性分類基線 |
| L0、L1(r=2) | 每任務完整 expert；共用底座＋rank 2 LoRA 的 expert |
| I6 | 用 VLM zero-shot 分數當底座的 LoRA expert，不依賴第一個任務（後來的「修正頭」） |
| e0.75、z0.75、腫瘤半 | NC-5 的背景向量；最像腫瘤的一半 |
