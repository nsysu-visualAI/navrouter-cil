## 2. 逐段判讀

### 2.1 S5：互補來自哪裡（這一段改變了結論）

四個判讀器單獨的 WP（告訴任務）：

| | 用文字比對（不訓練） | 用 ridge 判讀（closed-form） |
|---|---|---|
| 看全部 patch 的平均 | 0.776 | 0.924（整片統計 expert） |
| 看挑出的 64 個 patch | 0.934（主系統） | **0.946** |

| 讀法 | 數字 | 意思 |
|---|---|---|
| 挑 patch 有多重要 | 文字比對下 0.776 → 0.934；ridge 下 0.924 → 0.946 | 挑 patch 在兩種判讀下都有用 |
| 換判讀有多重要 | 64 個 patch 下 0.934 → 0.946 | 同樣的證據，ridge 比文字比對多對 1.2 pp |

| 組合 | 差在哪 | WP | 相對主系統 |
|---|---|---|---|
| 主系統＋整片 ridge（就是 M3） | 範圍與判讀都不同 | 0.9448 | +1.09 pp（8 折） |
| 主系統＋64 個 patch 的 ridge | 只有判讀不同 | 0.9444 | +1.04 pp（7 折） |
| 64 個 patch 的 ridge＋整片 ridge | 只有範圍不同 | 0.9462 | +1.22 pp（6 折） |
| 64 個 patch 的 ridge 單獨 | — | 0.9457 | +1.17 pp |

M3 的增益，用同一批 patch 換一種判讀就能拿到，不需要整片統計。「64 個 patch 的 ridge」在不告訴任務時：CIL ACC 0.9252，比主系統高 1.24 pp，十折贏 9 折。此時只有 seed 42、test 已看過，需 MOE-2 確認。

### 2.2 S1：M3 修好與弄壞了誰

| 類別 | 張數 | 修好 | 弄壞 | 主系統錯誤率 | M3 錯誤率 |
|---|---|---|---|---|---|

| 肺鱗癌 | 453 | 7 | 9 | 9.5% | 9.9% |

整片 ridge 偏向張數多的那一類（導管癌 761 對小葉癌 191）。修好與弄壞的片子在把握程度上分不開，這解釋了 gate 為什麼學不起來。

### 2.3 S2：CL 流程下的 M3

| 項目 | reverse | paper |
|---|---|---|
| Forgetting：主系統 → M3 | 0.0224 → 0.0216 | 0.0041 → 0.0086 |
| 最早學的任務的 WP（M3） | 食道 0.967 → 0.974 | 肺 0.921 → 0.911（掉 1.0 pp） |
| 標準差固定 對 重算 | 0.9233 對 0.9226 | 0.9217 對 0.9226 |

整片 ridge 每加一個任務就重解，舊任務那幾欄跟著變，幅度約 1 pp 以內。另驗證：正則化強度統一時，某任務的 TP 分數等於它兩個類別分數的和（差距 10⁻¹³ 以下）。

## 4. 創新要放在哪裡

| 試過的「混合」 | 結果 |
|---|---|
| 任務之間的 soft gating | 2,835 張只改 1 張 |
| 跨器官共用 head | 比不用 head 還差 |
| 任務內兩個 expert，每任務學一個權重 | 一個順序 +0.35 pp，另一個 −0.04 pp |
| 任務內兩個 expert，每張 slide 學一個權重 | 比固定相加差 |
| 兩個、三個同類 head 相加 | 幾乎沒有增益 |

| 有用的 | 結果 |
|---|---|
| TP 用 closed-form 的 ridge | 判器官 0.975，不存舊 slide |
| WP 加一個 closed-form 的判讀 | CIL ACC +1.0 到 +1.2 pp |

有用的兩件事是同一種機制：用累加統計量解出來的判讀。

MOE-2 還要回答：如果最後一步改成 ridge 判讀，head 還需不需要？

## 5. MOE-2 的項目與門檻（PREREG-18，摘要）

| 項目 | 內容 |
|---|---|
| 證據向量 v(s) | 用 seed s 的 head，四輪各 16 選 64 個 patch，原始 Z 等權平均後 L2 正規化 |
| LR(s) | 輸入 [v(s); 1]，8 類 one-hot，累加式 ridge；告訴任務時在真實任務兩類內判；CIL 時在 τ̂ 的兩類內判 |
| E1 多 seed 確認 | seed 42–46 各自的 LR 對主系統 |
| E2 是否需要 head | LR0 = 不用 head（g = 0）的 ridge |
| E3 一次取 64 | LR1 |
| E4 與整片向量合併 | LRG：輸入 [v; mean_vec; 1] |
| E5 類別加權 | LR-bal、GR-bal |
| E6 每類別 | 8 類各自正確率、balanced accuracy |
| E7 CL 流程 | 逐階段 ACC、Forgetting、BWT |
| G-LR | seed 43–46 各自 LR − 主系統 ≥ +0.007 且贏 ≥ 7 折 |
| G-HEAD | D_head ≥ +0.005 且 > 0 的折數 ≥ 7 |
| G-CAT | LRG − LR ≥ +0.005 且 > 0 的折數 ≥ 7 |
