## 1. 門檻結果

| 門檻 | 結果 | 數字 |
|---|---|---|
| 不用 head 的版本，t = 4 是否比主系統高 0.7 pp 以上 | 未通過 | +0.69 pp，贏 9 折。門檻是 +0.70 pp |

### 1.1 文字起點為什麼沒用

validation 上的目標值（不用 head、一次取 64 的向量）：

| 多相信文字（γ） | 0.001 | 0.01 | 0.1 | 1 | 10 |
|---|---|---|---|---|---|
| 目標值 | 0.9405 | 0.9384 | 0.9373 | 0.9315 | 0.916–0.923 |

越相信文字越差。最好的是 γ 最小的那一格，這時文字那一項小到不影響任何判定，等於一般的 ridge。

原因：我原本的假設是「資料少時文字比 ridge 可靠」。實際上一個任務有一百多張片子時，ridge 就已經不輸文字了。肺當第一個任務時，ridge 是 0.914，文字是 0.880。

這是一個負結果，記下來，不再往這個方向做。

### 1.2 第一個任務那個門檻怎麼讀

reverse 序的第一個任務是食道，每折的 test 只有約 15 張，一張就是 6.7 pp。

| 逐折差（不用 head 的 ridge − 主系統，t = 1） | 折數 |
|---|---|
| 相同 | 6 折 |
| 少對一張 | 3 折 |
| 多對一張 | 1 折 |

十折合計 150 張裡淨少 2 張。照規則是未通過，但這個差距沒有統計上的意義。

### 1.3 上一輪「資料少時會垮」的修正

| 系統 | 正則化強度 | reverse 序 t = 1（只學完食道） |
|---|---|---|
| 主系統（和文字比） | — | 0.961 |
| head ＋ ridge 判讀 | 0.00001（上一輪用的，選在候選值邊界） | 0.927 |
| head ＋ ridge 判讀 | 0.001 | 0.934 |
| 不用 head ＋ ridge 判讀 | 0.001 | 0.947 |

上一輪看到的 −3.4 pp，有一部分是正則化強度太小。這一批改成「看兩個順序、四個階段的 validation 平均」來選，三種輸入向量都選到 0.001，而且不在候選值邊界。

## 3. 定案建議

### 3.1 建議的系統

| 段 | 做法 |
|---|---|
| TP | 整片所有 patch 的平均向量，closed-form ridge，判器官 |
| 挑證據 | 該器官的 head 給每個 patch 打分（s0 加修正量），一次取分數最高的 64 個，等權平均 |
| WP | 上面那個向量，closed-form ridge 判讀，正則化強度 0.001 |

| 為什麼選它 | 依據 |
|---|---|
| 照事先的規則 | 上一份文件的判讀表：不用 head 的版本沒過門檻，就維持有 head 的 ridge 判讀或 M3 |
| 分數 | t = 4 CIL ACC 約 0.925，是目前候選裡最高的一組，對主系統 p = 0.014 |
| 不選 M3 的原因 | M3 犧牲小葉癌（71.2%）、結果和順序有關、要另外存標準差 |
| 保留老師規劃的結構 | 分派器加每任務一個低秩模組。創新落在兩處的 closed-form 判讀，以及「判器官看整片、判亞型看挑出的證據」 |
| 簡單 | 一次取 64，沒有「輪」和扣分係數；選 patch 的方式和 head 訓練時一致 |

不用 head 的版本不丟掉，放進消融表：拿掉 head 掉 0.4–0.5 pp，整個系統不訓練也有 0.920。這一列對審稿人有說服力，也讓老師看到 head 的實際貢獻有多少。

### 3.2 這個建議還缺什麼

| 缺的 | MOE-4 怎麼補 |
|---|---|
| 正則化強度 0.001 配 head 的向量，只有 seed 42 | seed 43–46 各跑一次，事先寫好門檻 |
| 「一次取 64」配 head 的向量，只有 seed 42、而且是舊的正則化強度 | 同上，並和四輪比 |
| 另外四個 seed 的逐階段結果 | 補上，包括主系統的 |
| 每類別（小葉癌） | 五個 seed 合計 |

### 3.3 如果 MOE-4 沒過

| 情況 | 定案 |
|---|---|
| 確認門檻沒過 | 退回 MOE-2 已確認的版本：head、四輪、ridge 判讀；正則化強度的問題照實寫 |
| 只有「一次取 64」不如四輪 | 用四輪版本 |

## 6. 本頁代號

| 代號 | 意思 |
|---|---|
| TP／WP | 判器官／在該器官內判亞型 |
| CIL ACC | 不告訴任務時 8 類的正確率 |
| 主系統 | ridge 判器官；每任務一個 head 挑 64 個 patch（四輪），平均後和亞型文字比 |
| head | 每任務一個的 residual scoring head（1,033 參數），決定挑哪些 patch |
| s0 | 不用訓練的 patch 分數 |
| ridge 判讀 | 挑出的 patch 平均成一個向量後，用 closed-form 的 ridge 分類，不和文字比 |
| 正則化強度（γ） | ridge 裡壓住權重大小的係數；太小時資料少的任務會不穩 |
| 以文字為起點的 ridge 判讀 | 把 ridge 的「權重盡量小」改成「權重盡量接近文字向量」；這一批證實沒有用 |
| M3 | 主系統的分數與整片統計 expert 的分數相加 |
| 一次取 64／四輪 | 直接取分數最高的 64 個／分四輪各取 16 個並避開相似的 |
| 四階段平均 ACC（Ā） | t = 1 到 4 每個階段 ACC 的平均 |
| Forgetting、BWT | 每個任務「歷史最高減最後」的平均；「最後減剛學完」的平均 |
| balanced accuracy | 兩個類別各自的正確率取平均 |
| seed | 訓練的隨機種子 |
| reverse／paper | 兩種任務順序：食道→腎→乳房→肺；肺→乳房→腎→食道 |
| G-CONF、G-TRAJ、G-ONE | MOE-4 的三個門檻：t = 4 是否比主系統好；四階段平均是否不比主系統差；一次取 64 是否不比四輪差 |

| P-F、P-4、P-T1、P-main、P-0 | MOE-4 的五個系統：定案候選；四輪版本；主系統改成一次取 64；主系統；不用 head |
