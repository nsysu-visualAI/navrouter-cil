## 2. 機制鏈：I6 做了什麼

| 步驟 | 內容 |
|---|---|
| 介入 | expert 的分數改成「VLM zero-shot 分數＋每任務一個很小的修正 g」；修正一開始是 0，訓練時才長出來 |
| 狀態 | 修正的大小（g 對 s0 的標準差比值）：食道 0.31、腎 0.56、乳房 1.86、肺 1.21 |
| 行為 | 食道的選片和 zero-shot 重疊 63%，其他三個任務只重疊 31–35%；和完整 expert（L0）只重疊 14–24% |
| 指標 | WP 0.934；每任務 1,033 參數；ACC 兩序都是 0.913 |

| # | 看到的 | 代表什麼 |
|---|---|---|
| 1 | 食道、腎的修正小於 zero-shot 分數；乳房、肺的修正大於 zero-shot 分數 | VLM 本身對食道、腎已經夠用，對乳房（乳管 vs 小葉）和肺（腺癌 vs 鱗癌）不夠 |
| 2 | NC-4 的「容量依需求」也是食道、腎常選「不訓練」 | 兩個獨立實驗指向同一件事 |
| 3 | I6、LoRA、完整 expert 選到的 patch 大多不同，WP 卻差不多 | 能支撐正確診斷的 patch 不只一組 |

## 5. 老實版：I6 算不算創新

| 項目 | 內容 |
|---|---|
| 相近的前人做法 | CLIP-Adapter、Tip-Adapter：在 zero-shot 的輸出上加一個殘差修正，用在分類 |
| 我們的差別 | (1) 修正的是「挑哪些 patch」的分數，不是分類結果；(2) 用在持續學習：每任務的 expert 只依賴 VLM 先驗，不依賴先學過的任務；(3) 修正大小可以當作「這個任務離 VLM 先驗多遠」的量尺 |
| 強度 | 中等。它是讓系統性質變好（與順序無關、儲存 3%），不是讓分數變高 |

## 9. 本頁代號

| 代號 | 意思 |
|---|---|
| I6 | expert 分數 = VLM zero-shot 分數＋每任務一個很小的修正；每任務 1,033 參數（修正頭） |
| D1、D2、D3 | AR＋LoRA r=2；AR＋完整 expert；AR＋I6（主系統） |
| AR、AR-bal | 解析式 router；每任務權重相同的版本 |
| LIN8 | 不用 expert、不用 router 的 8 類線性基線 |
| 轉交 | router 沒把握的片子交給病理醫師 |
| CLIP-Adapter、Tip-Adapter | 在 zero-shot 輸出上加殘差修正的前例 |
