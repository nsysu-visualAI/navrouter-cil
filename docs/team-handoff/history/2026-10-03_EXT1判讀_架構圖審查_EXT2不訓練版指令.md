## 2. 架構圖審查

整體流程正確：凍結編碼 → 判任務 → 該任務挑證據 → 閉式解讀出，底部的 CL 與推論兩條線也對。要改的集中在第 2 面板右半的讀出公式。

| # | 位置 | 圖上寫的 | 應該是 | 嚴重度 |
|---|---|---|---|---|
| 1 | 面板 2「Task-specific readout」 | A_τ = Σ v vᵀ（512×512）、B_τ = Σ v（512）、W_τ（512×2）、ŷ = vᵀW_τ | 讀出不是每任務一組，是和 TP 同一種累加式 ridge：v 補一維常數成 [v;1]（513）；A = Σ [v;1][v;1]ᵀ（513×513，所有任務共用累加）；B = Σ [v;1] yᵀ（513×2C，每任務加兩欄，y 是類別 one-hot）；W = (A+γI)⁻¹B（513×2C）；推論時 ŷ = [v;1]ᵀW 只在 τ̂ 的兩欄內 argmax。B_τ = Σ v 沒有標籤，數學上就錯了 | 重大 |
| 2 | 面板 2 標題與框名 | 「Task-specific readout (closed-form)」 | 「Accumulated readout (closed-form, sums only)」；標題「trained per task τ」只對 head 成立，讀出不是訓練 | 重大（與 #1 一起改） |
| 3 | 面板 3 | C = [Σ x]（513×T） | C = Σ x yᵀ（513×T），y 是任務 one-hot；寫法要和面板 2 的 B 一致，讓讀者看出 TP 與讀出是同一個機制用在兩種向量上 | 中 |
| 4 | 面板 2「Class-guided scoring」 | s_i = s0_i + g_i，沒說 s0、g 是什麼 | 加一行：s0_i = z-scored max cosine(z_i, t_c) over the task's two classes；g_i = head_τ([z_i; max cos; entropy])；套 B 就是 g_i ≡ 0，可用虛線框標「learned correction (optional)」，一張圖兩套通用 | 中 |
| 5 | 面板 2「Select 64 patches」 | 4 rounds × 16 | 加「with redundancy penalty λ」；沒有這個，四輪和一次挑 64 沒有差別，老師會問 | 中 |

| 8 | 標題「Hierarchical」 | 系統裡沒有層級（沒有 region → patch） | 若保留要在文中定義；否則改 multi-round 或 iterative。老師問「哪裡 hierarchical」會答不出來 | 中 |
| 9 | 面板順序 | 1 嵌入 → 2 挑證據 → 3 判任務 | 推論順序是 1 → 判任務 → 挑證據與讀出；建議調成左到右就是推論順序，底部的 Inference 框就不用再解釋 | 建議 |

## 4. 約法三章

| 代號 | 意思 |
|---|---|
| FINAL-A | 原 FINAL：AR TP + head 四輪 + [v;1] 累加式 ridge 讀出，γ = 1e-3，五 seed |
| FINAL-B | 同上拿掉 head，s = s0，不訓練、無 seed；γ 用同一條驗證規則重選 |
| s0 | patch 對該任務兩類文字的最大 cosine，z-score 後的分數 |
| g | head 對 patch 的修正量；FINAL-B 中恆為 0 |
| 累加式 ridge | A = Σ[v;1][v;1]ᵀ 跨任務共用，B 每任務加兩欄，W = (A+γI)⁻¹B |
| PREREG-22 | EXT-2 的預註冊規則 |
| 同折配對 | 同 fold、同序逐折比，報贏的折數、符號檢定 p、bootstrap CI |
| 質性圖 | 在 slide 縮圖上標出四輪選出的 64 個 patch 的圖；需要特徵檔有座標 |
